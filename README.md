## My approach

**1. Define the outcome.** Specify what the finished result should actually do, rather than simply ask an AI to “make something.”

**2. Challenge the design.** Question context usage, functionality, assumptions and trade-offs.

**3. Iterate on requirements.** Correct what was misunderstood and refine constraints based on observed output.

**4. Separate ideas from results.** A proposed architecture, a prompt and a working implementation are different levels of evidence.
