# Prompt Optimisation — Experiment Notebook

**Status: Planned.**

Document one controlled improvement at a time: output format, context, examples, constraints or instructions. Avoid changing several variables together unless comparing full prompt packages.

For each experiment record:
- **Question:** What property should improve?
- **Baseline:** Full original prompt.
- **Variant:** Full revised prompt and exact differences.
- **Fixed conditions:** Model/version, settings and test set.
- **Metric:** Accuracy, format compliance, latency or another operational measure.
- **Observed results:** Raw responses and scores, including failures.
- **Conclusion:** Supported finding, uncertainty and next test.

Use `templates/project-case-study.md` to start a documented experiment.
