# AI Model Comparison — Evaluation Plan

**Status: Planned; no measured results yet.**

## Research question
How reliably do two or more AI models complete the same software requirements?

## Fair comparison protocol
- Give each model the *identical initial brief* and an equal iteration budget.
- Record the exact model/version, date, tools available and sampling settings.
- Use the same objective scoring rubric (e.g., five functional requirements, each pass/fail).
- Save outputs, test logs and human-review notes.
- Repeat trials; avoid selecting only the best-looking output.
- Report unknown or unavailable usage costs instead of guessing.
