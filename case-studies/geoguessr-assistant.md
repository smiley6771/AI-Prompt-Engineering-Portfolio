# GeoGuessr Meta Research Assistant

**Area:** AI product concept / image analysis / knowledge organisation  
**Stage:** Project concept

## The idea

I proposed an AI-assisted tool to build a personal library of GeoGuessr **metas** — recognisable clues that can help identify a place — and analyse Street View imagery to discover additional clues.

## Requirements I identified

- Build and organise a reusable library of geographic clues.
- Analyse visual information from Street View.
- Connect observations with potentially useful location indicators.
- Expand the library as new evidence appears.

## Design questions

Such a system would need to distinguish reliable visual indicators from guesses. A useful library should record **why** a clue suggests a location, not just produce a confident answer.

## What this demonstrates

This is an example of framing a more ambitious AI application: combining visual analysis, structured information and a repeatable research workflow.

This page documents the concept, not a claim that a working system or validated meta library has been completed.
