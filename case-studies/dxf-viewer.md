# DXF Viewer for a CNC Workflow

**Area:** AI-assisted software specification / file visualisation  
**Stage:** Requirements concept

## The problem

In a CNC workflow, accepting a DXF upload is not enough if the operator cannot see the drawing. I specified that a DXF file should be **rendered on the screen**, not merely uploaded or identified.

## My requirement

> When a DXF file is uploaded, the user needs to see the actual drawing on screen.

This was part of a project brief concerning a Volta CNC machine.

## Why that detail matters

The difference between **file upload support** and **an actual drawing preview** is an important acceptance criterion. A successful implementation would need to display the geometry so the user can verify what was imported.

## What this demonstrates

I identified a concrete user-facing feature and made the expected behaviour explicit for an AI coding tool.

I am not claiming here that a completed viewer exists or that its DXF rendering has passed tests.
